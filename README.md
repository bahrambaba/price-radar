# 💰 Price Radar - (فعلا غیر فعال شده است)رادار قیمت لحظه‌ای

chandshode.com 

## 🚀 Features

- ✅ Real-time prices from chandshode.com
- ✅ Gold, coins, and currency tracking
- ✅ Persian date and time
- ✅ Automatic updates every 30 minutes
- ✅ GitHub Actions for automation

## 🛠️ Usage

### Local

```bash
pip install -r requirements.txt
python main.py
```

### GitHub Actions

The workflow runs automatically every 30 minutes. You can also trigger it manually from the Actions tab.
